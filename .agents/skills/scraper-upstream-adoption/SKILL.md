name: scraper-upstream-adoption
description: Adopt or update upstream picker, selector, or crawler code in Visual Scraper while preserving provenance, license, and behavior.
---

Read the upstream repository at a pinned revision. Identify the smallest reusable components and their direct dependencies. Record copied paths, source revision, license, and product changes in `THIRD_PARTY_NOTICES.md`. Preserve required copyright and permission notices in distributed artifacts. Run the imported component's applicable tests and the new integration path. Report source behavior that was deliberately changed.
